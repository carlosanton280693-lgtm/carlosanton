# Carlos Antón — HR Operations Résumé Site

A single-page personal site for Carlos Alfredo Antón Gutiérrez, showcasing his background in U.S. and multi-country HR operations, HRIS, and compliance. It presents a home hero, an about section, a career timeline, a skills/toolkit overview, an education/languages summary, and a contact section, all as client-side tabs within one page.

## Key technologies

- Plain HTML, CSS, and vanilla JavaScript — no build step or framework.
- Google Fonts (Space Grotesk, Inter, JetBrains Mono) loaded via `<link>` tags.
- A small canvas-based particle animation for the hero background.
- Deployed on Netlify as a static site (see `netlify.toml`).

## Running locally

Open `index.html` directly in a browser, or serve it with any static file server, for example:

```bash
npx serve .
```

Or with the Netlify CLI:

```bash
netlify dev --port 8889
```
